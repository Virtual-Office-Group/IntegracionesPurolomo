## Integración de órdenes de producción

### Estructura básica

```json
{
    "prodOrder": "PROD001",
    "prodOrderExt": "PRODEXT001",
    "locationCode": "MP",
    "type": "PBA"
    "tag": "13244234",
    "productionOrderlines":[
        {
            "itemNoExt": "PTCM10",
            "unitMeasureCode": "KG",
            "quantity": 10,
            "productionOrderComponents":[
                {
                    "itemNoExt":"MP003",
                    "unitMeasureCode": "KG",
                    "estimatedquantityPer": 1,
                    "realquantityPer": 3
                }
            ]
        }
    ]
}
```

### Creación de tickets de producción (ABA)

Las ordenes de produccion provenientes de ABA provienen de una orden de produccion externa, por lo que se debe enviar el campo prodOrderExt con el valor de la orden de produccion externa. Y asociarse a la orden de produccion interna que se genere en Business Central, la cual se enviara en el campo prodOrder. Los componentes de la orden de produccion se deben enviar en la propiedad `productionOrderComponents`.

Para crear tickets de producción se debe utilizar la siguiente estructura:


```json
POST
https://devnamespacevog.servicebus.windows.net
Header{
  Content-Type: application/json
  Authorization: Bearer {SharedAccessSignature}
  companyID: {companyID} // Id de la compañía en Business Central
  environment: {environment} // Nombre del ambiente en Business Central
  operationType: "POST" // Tipo de operación
  requestId: {requestId} // Id del mensaje
}
body
{
    "prodOrder": "OPL001",
    "prodOrderExt": "PROD0004",
    "type": "ABA",
    "productionOrderlines":[
        {
            "itemNoExt": "PTCM10",
            "unitMeasureCode": "UND",
            "quantity": 10,
            "productionOrderComponents":[
                {
                    "itemNoExt":"mp003",
                    "unitMeasureCode": "KG",
                    "estimatedquantityPer": 1,
                    "realquantityPer": 3
                }
            ]
        }
    ]
} 
```

Las ordenes de produccion provienen de una produccion ABA, y se registrar como recibo de produccion parcial bajo una orden de produccion interna, por lo que se debe enviar el campo prodOrder con el valor de la orden de produccion interna.

### Obtener lista de órdenes de producción

**Consumir endpoints**

Para consultar manualmente las órdenes de producción, puedes consumir el endpoint personalizado de Business Central.
```json
GET 
https://api.businesscentral.dynamics.com/v2.0/{{TenantID}}/{{environmentName}}/api/virtualOfficeGroup/integration/v1.0/companies({{companyId}})/prodOrders?$expand=prodOrderLines
Content-Type: application/json
Authorization: Bearer {access_token}
```

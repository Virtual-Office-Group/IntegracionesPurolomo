### Creación de tickets de producción (ABA)

Las ordenes de produccion provenientes de ABA provienen de una orden de produccion externa, por lo que se debe enviar el campo prodOrderExt con el valor de la orden de produccion externa. Y asociarse a la orden de produccion interna que se genere en Business Central, la cual se enviara en el campo prodOrder. Los componentes de la orden de produccion se deben enviar en la propiedad `productionOrderComponents`.

Para crear tickets de producción se debe utilizar la siguiente estructura:


```json
POST
https://devnamespacevog.servicebus.windows.net
Header{
  Content-Type: application/json
  Authorization: Bearer {SharedAccessSignature}
  companyID: {companyID} // Id de la compañía en Business Central
  environment: {environment} // Nombre del ambiente en Business Central
  operationType: "POST" // Tipo de operación
  requestId: {requestId} // Id del mensaje
}
body
{
    "prodOrder": "OPL001",
    "prodOrderExt": "PROD0004",
    "type": "ABA",
    "tag": "12434",
    "productionOrderlines":[
        {
            "itemNoExt": "PTCM10",
            "unitMeasureCode": "UND",
            "quantity": 10,
            "productionOrderComponents":[
                {
                    "itemNoExt":"mp003",
                    "unitMeasureCode": "KG",
                    "estimatedquantityPer": 1,
                    "realquantityPer": 3
                }
            ]
        }
    ]
} 
```

# Consumo de maestros de datos

## Consumo de órdenes de producción


**Suscripción del recurso por webhook**

```json
POST
https://api.businesscentral.dynamics.com/v2.0/{{TenantID}}/{{enviromentName}}/api/virtualOfficeGroup/integration/v1.0/subscriptions
Content-Type: application/json
Authorization: Bearer {access_token}
body
{
  "notificationUrl": "%UrlNotificationId%",
  "resource": "virtualOfficeGroup/integration/v1.0/companies({{companyId}})/prodOrders",
  "clientState": ""
}
```

<Aside type="caution">
La suscripción de articulos se gestiona a través de una API personalizada. Para realizar la solicitud de suscripción, se debe utilizar la siguiente estructura de URL en el endpoint:

```text 
POST > https://api.businesscentral.dynamics.com/v2.0/{{TenantID}}/{{environmentName}}/api/virtualOfficeGroup/integration/v1.0/subscriptions
```
</Aside>

### Tipos de órdenes de producción

**ABA** 

las órdenes de producción de tipo ABA son aquellas que provienen de un sistema externo y se integran en Business Central para su seguimiento y gestión. Estas órdenes permiten registrar la producción de manera detallada, incluyendo los componentes necesarios para completar la orden.

**PBA**

las ordenes de producción de tipo PBA son aquellas que provienen de un recibo de produccion y se entregan de manera parcial diariamente.

**GLOBAL**

las ordenes de producción de tipo GLOBAL son aquellas que provienen de una produccion en alguna planta con el sistema GLOBAL, y se registrar como recibo de produccion completado bajo una orden de produccion interna. Solo reportan los microingrdientes.

#### Tipo de ubicaciones para ordenes de produccion en GLOBAL:

| **Santa Teresa** | Ubicación de la planta de producción en Santa Teresa. |
| **Cagua** | Ubicación de la planta de producción en Cagua. |
| **Valencia** | Ubicación de la planta de producción en Valencia. |

## Integración de ordenes de producción

### Estructura basica

```json
{
    "prodOrder": "PROD001",
    "prodOrderExt": "PRODEXT001",
    "locationCode": "MP",
    "lote": "13244234",
    "productionOrderlines":[
        {
            "itemNoExt": "PTCM10",
            "unitMeasureCode": "KG",
            "quantity": 10,
            "finishedQuantity": 10,
            "productionOrderComponents":[
                {
                    "itemNoExt":"MP003",
                    "unitMeasureCode": "KG",
                    "estimatedquantityPer": 1,
                    "realquantityPer": 3
                }
            ]
        }
    ]
}
```

#### Campos de la integración

##### Encabezado  

| Campo | Tipo de dato | Descripción |
| :--- | :--- | :--- |
| prodOrder | Text[20] | Nro. Orden de producción. |
| prodOrderExt | Text[255] | Nro. Orden de producción externa. |
| locationCode | Text[255] | Código de ubicación. |
| lote | Text[20] | Nro. de lote. |

##### Lineas

| Campo | Tipo de dato | Descripción |
| :--- | :--- | :--- |
| itemNoExt | Text[255] | Código del artículo externo | 
| unitMeasureCode | Text[255] | Código de la unidad de medida |
| quantity | Decimal | Cantidad del articulo | 
| finishedQuantity | Decimal | Cantidad finalizada |

#### Componentes 

| Campo | Tipo de dato | Descripción |
| :--- | :--- | :--- |
| itemNoExt | Text[255] | Código del artículo externo | 
| unitMeasureCode | Text[255] | Código de la unidad de medida |
| estimatedquantityPer | Decimal | Cantidad estimada por unidad |
| realquantityPer | Decimal | Cantidad real por unidad |

### Creacion tickets de produccion 

para crear tickets de produccion se debe utilizar la siguiente estructura:


```json
POST
https://devnamespacevog.servicebus.windows.net
Header{
  Content-Type: application/json
  Authorization: Bearer {SharedAccessSignature}
  companyID: {companyID} // Id de la compañía en Business Central
  environment: {environment} // Nombre del ambiente en Business Central
  operationType: "POST" // Tipo de operacion
  requestId: {requestId} // Id de mensaje
}
body
{
    "prodOrder": "OPL001",
    "prodOrderExt": "PROD0004",
```

## Consumo Ordenes de produccion

### Obtener lista de Ordenes de produccion

**Consumir Endpoints**

Para consultar manualmente las órdenes de producción, puedes consumir el endpoint estándar de Business Central.

```json
GET 
https://api.businesscentral.dynamics.com/v2.0/{{TenantID}}/{{enviromentName}}/api/virtualOfficeGroup/integration/v1.0/companies({{companyId}})/prodOrders?$expand=prodOrderLines
Content-Type: application/json
Authorization: Bearer {access_token}
```
